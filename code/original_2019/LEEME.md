# Scripts originales (2019)

Son las versiones de trabajo usadas durante la tesis, sin cambios de lógica. Solo se pasaron a codificación UTF-8 para recuperar las tildes.

- `01_BasinBasic.R`: delimitación de la cuenca de una planta (base de la versión ordenada en `code/01_delimitacion_cuencas.R`).
- `02_BasinGeneration1.R` y `03_Basin2.0.R`: borradores para generalizar la delimitación a todas las plantas a partir de un archivo de coordenadas (`pih.csv`). Están incompletos.

No corren tal cual: usan rutas del equipo original y paquetes retirados de CRAN (`rgdal`, `maptools`, `rgeos`). Se publican para documentar el proceso.
